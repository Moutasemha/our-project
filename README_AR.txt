دليل فعاليات الجامعة الافتراضية السورية — BWP401
==================================================

محتويات المشروع
- index.html: الصفحة الرئيسية والفعاليات البارزة والتصنيفات.
- events.html: قائمة الفعاليات مع البحث والفلترة حسب التصنيف والفترة والتاريخ المحدد والمكان.
- event.html: تفاصيل الفعالية، صورة، خريطة توضيحية، فعاليات ذات صلة، تقويم ومشاركة وحجز تجريبي.
- about.html: عن الدليل، الرؤية والرسالة والفريق ومعايير النشر.
- contact.html: نموذج تواصل مع تحقق JavaScript ورسائل نجاح/خطأ.
- assets/css/styles.css: الهوية البصرية والتصميم المتجاوب.
- assets/js/main.js: بيانات الفعاليات والتفاعلات.
- assets/img/: صور الفعاليات، وخريطة SVG ثابتة توضيحية.

بيانات الفعاليات
- يتضمن المشروع الفعاليات الست الواردة في ملف BWP401_Event_Guide المرفق.
- ورقة الوظيفة توضح أن بيانات الفعاليات في هذا النموذج توضيحية وليست إعلانات رسمية.
- مدة الفعاليات غير محددة في الملف، لذلك لا يعرض الموقع مدة مفترضة.

معلومات الفريق
- تظهر أسماء المشاركين وأرقامهم الجامعية وأدوارهم في الصفحة الرئيسية وصفحة «عن الدليل».

- الخريطة المرفقة رسم ثابت توضيحي وليست دليلاً جغرافياً دقيقاً؛ ملف الفعاليات لا يذكر عناوين تفصيلية.
